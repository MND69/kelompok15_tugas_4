# kelompok15_tugas_4

Aplikasi mobile interaktif berbasis Flutter yang mensimulasikan sistem pemantauan dan kontrol pembangkit energi terbarukan (Panel Surya dan Turbin Angin). Aplikasi ini dirancang untuk mendemonstrasikan implementasi layout kompleks dan 6 jenis manipulasi gesture interaktif yang memicu perubahan state visual secara real-time.
